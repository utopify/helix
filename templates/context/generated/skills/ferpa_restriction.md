# FERPARestriction

**Table:** `helix_silver.ferpa_restriction` · **Classification:** confidential · **FERPA education record:** yes · **GLBA:** no

A student's FERPA directory information restriction. When active, directory information must be withheld from any disclosure not covered by a FERPA exception. Every downstream consumer of HELIX student data MUST check this resource before disclosing directory information.

## Grain and keys

One row per FERPARestriction record, keyed by `helix_id`. Required references: `student_ref`.

## Joins

| Column | Joins to |
|--------|----------|
| `student_ref` | `helix_silver.student.helix_id` (Student) |

## Required filters and usage rules

- FERPA education record: access needs legitimate educational interest (99.31(a)(1)). Exclude students with an active directory restriction from anything shared outside the institution (ACM-SPECIAL-001).
- Publish counts only with small-cell suppression (N under 5) per govern/ferpa-suppression-policy.json.

## Columns

| Column | Definition |
|--------|-----------|
| `helix_id` | HELIX-assigned unique identifier. |
| `student_ref` | Reference to the HELIX Student resource. |
| `restriction_type` | Full = withhold everything. Directory = withhold directory info only. Partial = specific categories. |
| `restricted_categories` | Specific directory information categories restricted by the student. |
| `restrict_directory` | Master flag: if true, withhold ALL directory information. |
| `effective_date` | Date the restriction took effect. |
| `end_date` | Null if indefinite (most FERPA blocks persist until removed by the student). |
| `is_active` | Whether the restriction is currently in effect. |
| `requested_date` | Date the student submitted the restriction request. |
