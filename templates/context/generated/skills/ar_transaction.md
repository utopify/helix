# ARTransaction

**Table:** `helix_silver.ar_transaction` · **Classification:** confidential · **FERPA education record:** no · **GLBA:** yes

An accounts receivable / student financials transaction, a charge, payment, or refund on a student account. FERPA/GLBA-relevant when linked to a student and financial aid.

## Grain and keys

One row per ARTransaction record, keyed by `helix_id`. Required references: none.

## Joins

| Column | Joins to |
|--------|----------|
| `student_ref` | `helix_silver.student.helix_id` (Student) |
| `term_ref` | `helix_silver.academic_period.helix_id` (AcademicPeriod) |

## Columns

| Column | Definition |
|--------|-----------|
| `helix_id` | HELIX-assigned unique identifier for this ARTransaction record. |
| `transaction_id` | Direct map. |
| `student_ref` | Resolve customer to HELIX student_id. In Workday Student, Customer = Student record. |
| `transaction_type` | Map: Customer Invoice → 'charge', Customer Payment → 'payment', Customer Refund → 'refund', Credit Memo → 'adjustment'. |
| `charge_code` | Map Workday Revenue Category to HELIX charge code. E.g., 'Tuition - Undergraduate' → 'tuition_ug'. |
| `description` | Direct map. |
| `amount` | Charges positive, payments/refunds negative. |
| `currency` | ISO 4217. Direct map. |
| `transaction_date` | Cast to ISO 8601. |
| `due_date` | Cast to ISO 8601. |
| `term_ref` | Link to HELIX AcademicPeriod. Institutions typically code tuition charges to an academic period. |
| `payment_method` | Map: 'Check' → 'check', 'ACH' → 'eft', 'Credit Card' → 'credit_card', 'Wire' → 'wire', 'Financial Aid' → 'fin_aid_disbursement'. |
| `invoice_status` | Map: 'Draft' → 'draft', 'Approved' → 'open', 'Paid' → 'paid', 'Partially Paid' → 'partial', 'Canceled' → 'void'. |
| `balance_due` | Direct map. Remaining balance after payments applied. |
| `fund_code` | Map to HELIX fund code. |
| `department` | Map to HELIX org code. |
| `third_party_ref` | If charge is covered by a third-party contract, reference the contract. |
