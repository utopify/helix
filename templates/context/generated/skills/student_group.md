# StudentGroup

**Table:** `helix_silver.student_group` · **Classification:** confidential · **FERPA education record:** yes · **GLBA:** no

A student's membership in an institutional group or cohort. Used for population management, IPEDS cohort tracking, targeted communications, and service delivery. Examples: student athletes, honors students, first-generation, veterans, TRIO participants.

## Grain and keys

One row per StudentGroup record, keyed by `helix_id`. Required references: `student_ref`.

## Joins

| Column | Joins to |
|--------|----------|
| `student_ref` | `helix_silver.student.helix_id` (Student) |

## Required filters and usage rules

- FERPA education record: access needs legitimate educational interest (99.31(a)(1)). Exclude students with an active directory restriction from anything shared outside the institution (ACM-SPECIAL-001).
- Publish counts only with small-cell suppression (N under 5) per govern/ferpa-suppression-policy.json.

## Columns

| Column | Definition |
|--------|-----------|
| `helix_id` | HELIX-assigned unique identifier. |
| `student_ref` | Reference to the HELIX Student resource. |
| `group_code` | Institutional group identifier (e.g., 'ATHL', 'HONORS', 'FIRSTGEN', 'VET', 'TRIO'). |
| `group_name` | Human-readable group name (e.g., 'Student Athletes'). |
| `group_category` | Classification of the group type. |
| `start_date` | Date the student joined this group. |
| `end_date` | Null if active membership. |
| `is_active` | Whether the membership is current. |
| `ipeds_cohort_id` | For IPEDS entry cohorts: the cohort identifier (e.g., 'FA2026-FTFT' = Fall 2026 First-Time Full-Time). |
| `sport_code` | For athletics groups: NCAA/NAIA sport code. |
| `scholarship_ref` | For scholarship cohorts: reference to the associated award/fund. |
