# Enrollment

**Table:** `helix_silver.enrollment` · **Classification:** confidential · **FERPA education record:** yes · **GLBA:** no

A student's registration in a specific course section during an academic period.

## Grain and keys

One row per Enrollment record, keyed by `helix_id`. Required references: `student_ref`, `course_section_ref`, `academic_period_ref`.

## Joins

| Column | Joins to |
|--------|----------|
| `student_ref` | `helix_silver.student.helix_id` (Student) |
| `course_section_ref` | `helix_silver.course_section.helix_id` (CourseSection) |
| `academic_period_ref` | `helix_silver.academic_period.helix_id` (AcademicPeriod) |

## Required filters and usage rules

- Exclude enrollment_status dropped and auditing when counting enrollment
- For official counts, use rows as of academic_period.census_date
- FERPA education record: access needs legitimate educational interest (99.31(a)(1)). Exclude students with an active directory restriction from anything shared outside the institution (ACM-SPECIAL-001).
- Publish counts only with small-cell suppression (N under 5) per govern/ferpa-suppression-policy.json.
