# AdmissionApplication

**Table:** `helix_silver.admission_application` · **Classification:** confidential · **FERPA education record:** yes · **GLBA:** no

An application for admission to the institution. Tracks the applicant's journey from submission through decision and enrollment intent.

## Grain and keys

One row per AdmissionApplication record, keyed by `helix_id`. Required references: `student_ref`, `admit_period_ref`.

## Joins

| Column | Joins to |
|--------|----------|
| `student_ref` | `helix_silver.student.helix_id` (Student) |
| `admit_period_ref` | `helix_silver.academic_period.helix_id` (AcademicPeriod) |
| `program_ref` | `helix_silver.program.helix_id` (Program) |

## Required filters and usage rules

- Count each applicant once per admit period and application type
- FERPA education record: access needs legitimate educational interest (99.31(a)(1)). Exclude students with an active directory restriction from anything shared outside the institution (ACM-SPECIAL-001).
- Publish counts only with small-cell suppression (N under 5) per govern/ferpa-suppression-policy.json.
