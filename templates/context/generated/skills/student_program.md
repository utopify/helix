# StudentProgram

**Table:** `helix_silver.student_program` · **Classification:** confidential · **FERPA education record:** yes · **GLBA:** no

A student's enrollment in an academic program (major, minor, concentration, certificate). A student may have multiple active program enrollments simultaneously (e.g., double major, major + minor).

## Grain and keys

One row per StudentProgram record, keyed by `helix_id`. Required references: `student_ref`, `program_ref`, `start_period_ref`.
