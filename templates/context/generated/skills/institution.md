# Institution

**Table:** `helix_silver.institution` · **Classification:** public · **FERPA education record:** no · **GLBA:** no

A higher education institution, university, college, community college, or system office.

## Grain and keys

One row per Institution record, keyed by `helix_id`. Required references: none.

## Required filters and usage rules

- Follow the classification above for any output.

| Column | Definition |
|--------|-----------|
| `helix_id` | Globally unique HELIX identifier |
| `name` | Official institution name |
| `short_name` | Common abbreviation (e.g., 'OSU', 'MIT') |
| `identifiers` | External identifiers (IPEDS UnitID, OPEID, HESA UKPRN, etc.) |
| `institution_type` | Institution type. *(generated from the name; steward to confirm)* |
| `carnegie_classification` | Carnegie Classification code (US institutions) |
| `country` | Country. *(generated from the name; steward to confirm)* |
| `state_province` | State, province, or region |
| `timezone` | IANA timezone (e.g., 'America/New_York') |
| `erp_system` | Primary SIS/ERP platform |
| `website` | Website. *(generated from the name; steward to confirm)* |
