# Licensure

**Table:** `helix_silver.licensure` · **Classification:** confidential · **FERPA education record:** yes · **GLBA:** no

A professional licensure or certification exam outcome (e.g., NCLEX for nursing, CPA, bar exam, Praxis for teaching, USMLE for medicine). Licensure pass rates are a core programmatic accreditation reporting requirement for many professional programs and a key student outcome metric.

## Grain and keys

One row per Licensure record, keyed by `helix_id`. Required references: `student_ref`.

## Required filters and usage rules

- FERPA education record: access needs legitimate educational interest (99.31(a)(1)). Exclude students with an active directory restriction from anything shared outside the institution (ACM-SPECIAL-001).
- Publish counts only with small-cell suppression (N under 5) per govern/ferpa-suppression-policy.json.

## Column rules

- `license_number`, `score`, `scaled_score`: confidential. License numbers identify a person; individual scores are education records. Programs report pass rates as suppressed aggregates.
