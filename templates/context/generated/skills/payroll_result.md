# PayrollResult

**Table:** `helix_silver.payroll_result` · **Classification:** restricted · **FERPA education record:** no · **GLBA:** no

A payroll result, a processed pay statement for one pay period: gross, taxes, deductions, net, and labor distribution across funds/grants. Restricted; contains tax-linked data.

## Grain and keys

One row per PayrollResult record, keyed by `helix_id`. Required references: `employee_ref`.

## Joins

| Column | Joins to |
|--------|----------|
| `employee_ref` | `helix_silver.employee.helix_id` (Employee) |
| `grant_ref` | `helix_silver.grant.helix_id` (Grant) |

## Required filters and usage rules

- Follow the classification above for any output.

## Column rules

- `gross_pay`, `net_pay`, `total_taxes`, `total_deductions`, `regular_earnings`, `overtime_earnings`, `supplemental_earnings`, `retirement_deduction`, `benefit_deductions`: restricted. Only helix_analyst_restricted_hr sees cleartext. Bank and routing numbers are not HELIX PayrollResult attributes and never leave the payroll system.

## Columns

| Column | Definition |
|--------|-----------|
| `helix_id` | HELIX-assigned unique identifier for this PayrollResult record. |
| `employee_ref` | Link to HELIX employee_id. |
| `pay_period_start` | Cast to ISO 8601. |
| `pay_period_end` | Cast to ISO 8601. |
| `pay_date` | Cast to ISO 8601. |
| `gross_pay` | Direct map. Sum of all earnings. |
| `total_taxes` | Federal + state + local + FICA. |

| `net_pay` | Gross - taxes - deductions. |

| `overtime_earnings` | OT earnings (non-exempt employees only). |
| `supplemental_earnings` | Additional earnings beyond regular pay. |
| `retirement_deduction` | 403(b), 457(b), state pension employee contribution. |
| `benefit_deductions` | Employee benefit premium contributions. |
| `cost_center` | Map to HELIX org code. Where the labor cost is charged. |
| `fund_code` | Map to HELIX fund code. Grant-funded positions → restricted fund. |
| `grant_ref` | If labor is charged to a grant. |
