# AidApplication

**Table:** `helix_silver.aid_application` · **Classification:** restricted · **FERPA education record:** yes · **GLBA:** yes

The FAFSA/ISIR (or institutional aid) application record for a student for a given aid year. Carries the Student Aid Index (SAI) that replaced EFC under FAFSA Simplification (2024-25), dependency status, Pell eligibility, verification selection, and NSLDS match flags. GLBA-covered customer information; classified restricted.

## Grain and keys

One row per AidApplication record, keyed by `helix_id`. Required references: `student_ref`.

## Required filters and usage rules

- FERPA education record: access needs legitimate educational interest (99.31(a)(1)). Exclude students with an active directory restriction from anything shared outside the institution (ACM-SPECIAL-001).
- GLBA-covered: only the restricted financial aid role sees cleartext; never return individual values in agent answers (govern/agent-guardrails.json).
- Publish counts only with small-cell suppression (N under 5) per govern/ferpa-suppression-policy.json.

## Column rules

- `sai`, `efc_legacy`, `pell_lifetime_eligibility_used`, `isir_transaction_number`, `comment_codes`, `c_flags`, `nslds_match_flags`: restricted (GLBA-covered). ISIR and FAFSA-derived values. Only helix_analyst_restricted_finaid sees cleartext; everyone else sees SHA-256 token or 'RESTRICTED'. Never surfaced in agent responses (agent-guardrails PQP-05).
- `dependency_override_flag`, `homeless_youth_flag`, `foster_care_flag`, `citizenship_status`, `professional_judgment_flag`: restricted (sensitive circumstance). Reveals personal circumstances (homelessness, foster care, citizenship). Only helix_analyst_restricted_finaid sees cleartext. Never used as a dimension in aggregates without small-cell suppression (ferpa-suppression-policy SUPP-001, SUPP-005).
