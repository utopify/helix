# LoanRecord

**Table:** `helix_silver.loan_record` · **Classification:** restricted · **FERPA education record:** yes · **GLBA:** yes

A Direct Loan, Perkins, or other education loan originated for a student: type, status, loan period, MPN and counseling status, amounts, rate, and COD/servicer linkage. GLBA-covered; classified restricted.

## Grain and keys

One row per LoanRecord record, keyed by `helix_id`. Required references: `student_ref`.

## Joins

| Column | Joins to |
|--------|----------|
| `student_ref` | `helix_silver.student.helix_id` (Student) |

## Required filters and usage rules

- FERPA education record: access needs legitimate educational interest (99.31(a)(1)). Exclude students with an active directory restriction from anything shared outside the institution (ACM-SPECIAL-001).
- GLBA-covered: only the restricted financial aid role sees cleartext; never return individual values in agent answers (govern/agent-guardrails.json).
- Publish counts only with small-cell suppression (N under 5) per govern/ferpa-suppression-policy.json.

## Column rules

- `gross_loan_amount`, `net_loan_amount`, `origination_fee`, `cod_loan_id`, `servicer_name`: restricted (GLBA-covered). Individual loan amounts and COD identifiers. Only helix_analyst_restricted_finaid sees cleartext. Aggregate loan volume by type is available in suppressed gold aggregates.
