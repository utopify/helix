# InternationalStudent

**Table:** `helix_silver.international_student` · **Classification:** restricted · **FERPA education record:** yes · **GLBA:** no

Immigration and visa data for a non-citizen student. Covers F-1, J-1, M-1 visa holders, SEVIS tracking, I-20/DS-2019 program dates, and work authorization (CPT/OPT). Classified as restricted due to immigration data sensitivity.

## Grain and keys

One row per InternationalStudent record, keyed by `helix_id`. Required references: `student_ref`.

## Required filters and usage rules

- FERPA education record: access needs legitimate educational interest (99.31(a)(1)). Exclude students with an active directory restriction from anything shared outside the institution (ACM-SPECIAL-001).
- Publish counts only with small-cell suppression (N under 5) per govern/ferpa-suppression-policy.json.

## Column rules

- `sevis_id`, `visa_type`, `visa_status`, `visa_issue_date`, `visa_expiry_date`, `i20_program_start_date`, `i20_program_end_date`, `work_authorization`, `sponsor`: restricted. Only helix_analyst_restricted sees cleartext. All others see 'RESTRICTED' literal. Export-controlled data.
