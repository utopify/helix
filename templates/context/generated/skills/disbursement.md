# Disbursement

**Table:** `helix_silver.disbursement` · **Classification:** restricted · **FERPA education record:** yes · **GLBA:** yes

An actual disbursement of a financial aid award to a student account for a term: scheduled vs actual dates, gross/net amounts, holds, refunds, and COD reporting status. Distinct from the FinAidAward offer. GLBA-covered; classified restricted.

## Grain and keys

One row per Disbursement record, keyed by `helix_id`. Required references: `student_ref`, `fin_aid_award_ref`.

## Joins

| Column | Joins to |

| `student_ref` | `helix_silver.student.helix_id` (Student) |
| `fin_aid_award_ref` | `helix_silver.fin_aid_award.helix_id` (FinAidAward) |
| `academic_period_ref` | `helix_silver.academic_period.helix_id` (AcademicPeriod) |

## Required filters and usage rules

- FERPA education record: access needs legitimate educational interest (99.31(a)(1)). Exclude students with an active directory restriction from anything shared outside the institution (ACM-SPECIAL-001).
- GLBA-covered: only the restricted financial aid role sees cleartext; never return individual values in agent answers (govern/agent-guardrails.json).
- Publish counts only with small-cell suppression (N under 5) per govern/ferpa-suppression-policy.json.

## Column rules

- `gross_amount`, `net_amount`, `fees_deducted`, `refund_amount`: restricted (GLBA-covered). Individual disbursement and refund amounts. Cleartext for helix_analyst_restricted_finaid and bursar staff holding helix_analyst_restricted. Totals by fund and term are available to helix_analyst_standard through suppressed gold aggregates.
