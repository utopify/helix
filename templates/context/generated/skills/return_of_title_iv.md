# ReturnOfTitleIV

**Table:** `helix_silver.return_of_title_iv` · **Classification:** restricted · **FERPA education record:** yes · **GLBA:** yes

A Return of Title IV (R2T4) calculation when a student withdraws, per 34 CFR 668.22: percent enrolled/earned, earned vs unearned aid, amounts returned by school and student, and any post-withdrawal disbursement. GLBA-covered; classified restricted.

## Grain and keys

One row per ReturnOfTitleIV record, keyed by `helix_id`. Required references: `student_ref`, `academic_period_ref`.

## Required filters and usage rules

- FERPA education record: access needs legitimate educational interest (99.31(a)(1)). Exclude students with an active directory restriction from anything shared outside the institution (ACM-SPECIAL-001).
- GLBA-covered: only the restricted financial aid role sees cleartext; never return individual values in agent answers (govern/agent-guardrails.json).
- Publish counts only with small-cell suppression (N under 5) per govern/ferpa-suppression-policy.json.
