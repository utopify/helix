# AcademicTermRecord

**Table:** `helix_silver.academic_term_record` · **Classification:** confidential · **FERPA education record:** yes · **GLBA:** no

A student's academic summary for a single academic period: term GPA, cumulative GPA, units attempted/earned, academic standing, and enrollment status. One record per student per period.

## Grain and keys

One row per AcademicTermRecord record, keyed by `helix_id`. Required references: `student_ref`, `period_ref`.

## Joins

| Column | Joins to |
|--------|----------|
| `student_ref` | `helix_silver.student.helix_id` (Student) |
| `period_ref` | `helix_silver.academic_period.helix_id` (AcademicPeriod) |

## Required filters and usage rules

- FERPA education record: access needs legitimate educational interest (99.31(a)(1)). Exclude students with an active directory restriction from anything shared outside the institution (ACM-SPECIAL-001).
- Publish counts only with small-cell suppression (N under 5) per govern/ferpa-suppression-policy.json.

## Columns

| Column | Definition |
|--------|-----------|
| `helix_id` | HELIX-assigned unique identifier for this term record. |
| `student_ref` | Reference to the HELIX Student resource. |
| `period_ref` | Reference to the HELIX AcademicPeriod resource. |
| `enrollment_status` | Enrollment load for this period. |
| `academic_level` | Academic level as of this period. |
| `units_attempted` | Credit hours attempted this period. |
| `units_earned` | Credit hours earned (passed) this period. |
| `units_passed` | Credit hours with passing grade (may differ from earned if institution distinguishes). |
| `quality_points` | Total quality points this period (grade points × credit hours per course). |
| `term_gpa` | GPA for this period only. |
| `cumulative_gpa` | Running cumulative GPA through this period. |
| `cumulative_units_earned` | Total earned units through this period (all terms). |
| `cumulative_units_attempted` | Total attempted units through this period. |
| `academic_standing` | Academic standing for this period. |
| `dean_list` | Whether the student made the Dean's List this period. |
| `academic_load` | Official academic load classification (drives financial aid eligibility). |
