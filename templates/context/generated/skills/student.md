# Student

**Table:** `helix_silver.student` · **Classification:** confidential · **FERPA education record:** yes · **GLBA:** no

A person in their capacity as a learner at an institution. References a Person resource for base identity. Contains student-specific attributes: status, academic level, GPA, program enrollment, and classification.

## Grain and keys

One row per Student record, keyed by `helix_id`. Required references: none.

## Required filters and usage rules

- Count enrolled students from Enrollment at census, not from student.status alone
- FERPA education record: access needs legitimate educational interest (99.31(a)(1)). Exclude students with an active directory restriction from anything shared outside the institution (ACM-SPECIAL-001).
- Publish counts only with small-cell suppression (N under 5) per govern/ferpa-suppression-policy.json.
