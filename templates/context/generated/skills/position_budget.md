# PositionBudget

**Table:** `helix_silver.position_budget` · **Classification:** internal · **FERPA education record:** no · **GLBA:** no

A position budget, funded amount, actuals, variance, and split funding across funds/grants for a position and fiscal year. Captures higher-ed split-funding and backfill patterns.

## Grain and keys

One row per PositionBudget record, keyed by `helix_id`. Required references: `position_ref`.

## Joins

| Column | Joins to |
|--------|----------|
| `position_ref` | `helix_silver.position.helix_id` (Position) |

## Required filters and usage rules

- Follow the classification above for any output.

## Columns

| Column | Definition |
|--------|-----------|
| `helix_id` | HELIX-assigned unique identifier for this PositionBudget record. |
| `position_ref` | Link to HELIX position_id. |
| `fiscal_year` | Direct map. |
| `budgeted_amount` | Total funded amount for this position/year. |
| `actual_spend` | Actual compensation + benefits cost. |
| `variance` | Positive = underspent, negative = overspent. |
| `funding_splits` | Array of {fund, cost_center, grant, percentage} objects. Sum of percentages = 100%. |
| `primary_fund` | Map to HELIX fund code. |
| `primary_cost_center` | Map to HELIX org code. |
| `department` | Map to HELIX org code. |
| `org_headcount_budget` | Planned headcount for the org. |
| `org_headcount_actual` | Current filled headcount. |
| `org_headcount_open` | Unfilled positions. |
