# AidPackage

**Table:** `helix_silver.aid_package` · **Classification:** restricted · **FERPA education record:** yes · **GLBA:** yes

Need analysis and packaging for a student for an aid year/period: full Cost of Attendance (COA) components, computed need, offered aid totals, unmet need, and professional judgment adjustments. GLBA-covered; classified restricted.

## Grain and keys

One row per AidPackage record, keyed by `helix_id`. Required references: `student_ref`.

## Joins

| Column | Joins to |
|--------|----------|
| `student_ref` | `helix_silver.student.helix_id` (Student) |
| `aid_application_ref` | `helix_silver.aid_application.helix_id` (AidApplication) |
| `academic_period_ref` | `helix_silver.academic_period.helix_id` (AcademicPeriod) |

## Required filters and usage rules

- Use packaging_status packaged or finalized for reporting
- FERPA education record: access needs legitimate educational interest (99.31(a)(1)). Exclude students with an active directory restriction from anything shared outside the institution (ACM-SPECIAL-001).
- GLBA-covered: only the restricted financial aid role sees cleartext; never return individual values in agent answers (govern/agent-guardrails.json).
- Publish counts only with small-cell suppression (N under 5) per govern/ferpa-suppression-policy.json.

## Column rules

- `sai`, `need`, `unmet_need`, `pj_reason`, `pj_adjustment_amount`: restricted (GLBA-covered). Need analysis and professional judgment detail. Only helix_analyst_restricted_finaid sees cleartext. COA components are institutional budgets and are not masked.
