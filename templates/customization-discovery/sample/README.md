# Sample

Fictional inventories for trying the diff tool. `baseline_inventory.csv` is a tiny vanilla Banner; `production_inventory.csv` adds a local package, a local trigger, a custom column on SGBSTDN, a local student type code, and a one-line change to a delivered package, and drops a delivered view. `sample_register.csv` is what `tools/diff_customizations.py --case-insensitive` produced from them.
