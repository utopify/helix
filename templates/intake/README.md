# Intake: Start Every HELIX Project Here

Step 1 of [START_HERE](../../START_HERE.md).

| File | Use it for |
|------|-----------|
| `institution-profile.md` | Fill it in by hand with your team |
| `institution-profile.yaml` | The same questions, machine-readable, for an AI assistant or scripts |
| `institution-profile.example.yaml` | A filled-in example: a PeopleSoft school with six Oracle databases and a legacy warehouse |

The profile answers the questions every implementation stalls on if nobody asks them early: which database is the reporting copy, whether the person ID is shared across modules, which report is the official number, and who signs off.
