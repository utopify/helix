# HELIX Documentation

Comprehensive reference documentation for the HELIX framework.

## Guides

| Document | Description |
|----------|-------------|
| [Resource Catalog](resource-catalog.md) | All 15 HELIX Core resources with attributes, required fields, and domain groupings |
| [Terminology Catalog](terminology-catalog.md) | All 18 terminology code sets with every valid code, display name, and usage context |
| [Bridge Reference](bridge-reference.md) | ERP mapping overview for Banner, PeopleSoft, Workday, and Colleague |
| [Govern Overview](govern-overview.md) | Governance roles, quality rules, maturity model, and domain taxonomy |
| [Connect Overview](connect-overview.md) | API reference with all 16 endpoints, security model, and bulk export workflow |

## Quick Start

**I'm a data architect:** Start with the [Resource Catalog](resource-catalog.md) to understand the canonical data model, then review the [Terminology Catalog](terminology-catalog.md) for standardized code sets.

**I'm implementing HELIX at my institution:** Start with the [Bridge Reference](bridge-reference.md) to find your ERP's mapping templates, then use the [Resource Catalog](resource-catalog.md) as your target schema reference.

**I'm a CDO or governance lead:** Start with the [Govern Overview](govern-overview.md) for roles, quality rules, and the maturity model.

**I'm building integrations:** Start with the [Connect Overview](connect-overview.md) for the API specification.
