# Landing Zones

How to land SaaS systems in a HELIX lakehouse using what each subscription already includes, then enrich the data in silver and gold so your AI agents have one trusted source across every system.

| Guide | Covers |
|-------|--------|
| [`workday-landing-zone.md`](workday-landing-zone.md) | Workday HCM, Financials, and Student through RaaS and Web Services; where Prism and Workday Data Cloud fit |
| [`salesforce-landing-zone.md`](salesforce-landing-zone.md) | Agentforce Education (formerly Education Cloud), EDA, and NPSP or Nonprofit Cloud through Bulk API, Change Data Capture, and Amazon AppFlow; where Data 360 fits |

On-premises systems have their own extraction playbooks: `bridge/peoplesoft/PS_EXTRACTION.md` and `bridge/banner/ONPREM_EXTRACTION.md`. Banner SaaS is in `docs/banner-saas-landing-architecture.md`.

Start with [`../own-your-intelligence.md`](../own-your-intelligence.md) for why HELIX puts the intelligence layer in your lakehouse.
