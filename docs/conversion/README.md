# HELIX Conversion Guides

Find every customization in PeopleSoft or Banner, decide what happens to each one, and convert the parts worth keeping.

| Guide | Use it for |
|-------|-----------|
| [`customization-discovery.md`](customization-discovery.md) | The method: baseline, inventory, diff, enrich, decide, convert, prove |
| [`peoplesoft-customizations.md`](peoplesoft-customizations.md) | PeopleSoft Campus Solutions, HCM, and Financials, to Workday or a lakehouse |
| [`banner-customizations.md`](banner-customizations.md) | Banner on-prem to Banner SaaS or a lakehouse |

Everything you run is in [`templates/customization-discovery/`](../../templates/customization-discovery/). The AWS services for each step are in [`../aws-services-guide.md`](../aws-services-guide.md). For help as you go, load [`agents/customization-discovery-agent.json`](../../agents/customization-discovery-agent.json).
