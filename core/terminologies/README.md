# HELIX Terminologies

Standard code sets used across HELIX Core resources. Each terminology defines the valid values for a bound attribute.

Planned terminologies:
- `student-status.json` — Student lifecycle statuses
- `enrollment-status.json` — Enrollment/registration statuses
- `period-type.json` — Academic period types
- `grade-mode.json` — Grading modes
- `gender.json` — Gender codes
- `residency.json` — Residency classifications
- `data-classification.json` — Data classification tiers (HELIX Govern)
